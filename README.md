# Adidas US Sales Analysis Dashboard (Power BI)

## Overview
An interactive Power BI dashboard built to analyze Adidas US retail sales, operating profit, units sold, and regional performance.

## Key Insights & Metrics
- **Tools Used:** Power BI, DAX, Microsoft Excel
- **Key DAX Measures:** Profit-per-unit, Month-over-Month (MoM) Sales Growth, Operating Margin %
- **Data Cleaning:** Standardized date formats, handled missing values, and reconciled regional sales figures in Excel before modeling.
